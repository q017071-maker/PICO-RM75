# 第三方依赖与来源

- PICO Integration3.4.0：从[PICO官方资源](https://developer.picoxr.com/resources/?platform=unity)或[官方仓库](https://github.com/Pico-Developer/PICO-Unity-Integration-SDK)取得，遵守该SDK条款。源码仓库不再分发SDK本体；解压后按操作手册放到deployment/vendor指定目录。[官方导入说明](https://developer.picoxr.com/document/unity/import-the-sdk/)。
- Unity2022.3.62f3及Android工具链：通过Unity Hub安装并在各电脑授权，不提交编辑器、Android SDK/NDK/JDK或许可证。Unity包按`project/Packages/manifest.json`及`packages-lock.json`解析。
- RealMan Python SDK：`robotic-arm==1.1.6`，按`deployment/requirements.txt`安装于本机虚拟环境，不提交原生库副本。[PyPI版本页](https://pypi.org/project/robotic-arm/1.1.6/)。
- RM75-6FB可视化模型：RealManRobot/rm_models，固定提交`9d37f52605aa00c7b0ed8143e5e46b8ffdb9317a`；保留`project/Assets/ThirdParty/RealMan/RM75_6FB/LICENSE`（Apache2.0）与`SOURCE.md`及原始URDF/STL。
- `project/Assets/Samples/XR Interaction Toolkit/2.6.4/`为Unity包导入样例；使用遵守上游包的许可条款。这里保留现有场景引用，避免换电脑丢失GUID；本项目未重新声明样例所有权。

本次发布没有替第三方或整个既有项目擅自添加新的开源授权。不得把个人Unity许可证、Android签名密钥、GitHub凭据、设备配置文件或现场运行日志提交到源码仓库。
